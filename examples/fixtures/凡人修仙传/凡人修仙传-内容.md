# 凡人修仙传

《凡人修仙传》是网络作家忘语创作的仙侠修真小说，被誉为"凡人流"开山之作。全书分为人界篇、灵界篇、仙界篇三大部分。

## 作品概要

一个出身贫寒的山村少年韩立，偶然踏入修仙世界。他资质平庸、出身低微，在残酷的修真界中凭借谨慎、坚毅和机缘一步步成长，最终飞升仙界，成为时间道祖。

## 三界体系

### 人界篇
故事开篇所在界面。灵气稀薄，修士最高修炼至化神期。主要区域包括天南、乱星海、大晋等。韩立在此从炼气期修炼至化神期，渡飞升之劫前往灵界。

### 灵界篇
韩立飞升后的界面。灵气浓郁，种族林立，包括人族、妖族、魔族、夜叉族等多个种族。最高可修炼至大乘期。韩立在此建立青元宫，成为灵界顶尖强者。

### 仙界篇
终极界面。韩立飞升仙界后从真仙一步步修炼至金仙、太乙、大罗，最终掌握时间法则成为道祖。

## 主角：韩立

韩立，人称"韩跑跑"（因极其谨慎、遇险就跑）。出身天南越国一个普通山村，偶然进入七玄门，从此踏上修仙之路。

### 灵根资质
韩立为四属性伪灵根（金、木、火、土），修仙资质极差，被正道宗门视为废材。正常情况下，伪灵根能修炼到筑基期已是极限。但韩立凭借掌天瓶的逆天功效，硬生生突破了资质的限制。

### 性格特点
- 谨慎多疑：遇事先想退路，绝不冒险
- 心智坚韧：废材资质却从不放弃
- 心思缜密：做事滴水不漏，善用计谋
- 重情义但不迂腐：对朋友尽责，但该断则断

### 修炼历程

**人界时期**：七玄门入门 → 黄枫谷筑基 → 乱星海结丹 → 天南元婴 → 大晋化神 → 飞升灵界

**灵界时期**：天渊城立足 → 建立青元宫 → 合体期 → 大乘期 → 飞升仙界

**仙界时期**：真仙 → 金仙 → 太乙玉仙 → 大罗金仙 → 时间道祖

### 核心法宝

**掌天瓶**：韩立最神秘的法宝，一个巴掌大小的翠绿色小瓶。可以吸收月光精华，凝聚出参天造化液。这种绿色液体能一夜之间催熟数百年药龄的灵药，也可直接服用增强修为。掌天瓶是韩立崛起的根本原因，其真正来历直到仙界篇才揭晓——它与时间法则的起源有关。

**青竹蜂云剑**：韩立的本命法宝，一套七十二口飞剑。以万年青竹和蜂云晶炼制，锋利无比，可结成剑阵困杀敌人。

**风雷翅**：用雷鹏之羽和风灵之力炼制的飞行法宝，双翅一展可瞬息千里，是韩立逃命和追击的最大依仗。

**噬金虫**：一种上古奇虫，通体金色，可吞噬万物。从幼虫培养到成熟体后，数以万计的噬金虫群连大乘期修士都要退避三舍。韩立花费大量心血培养，成为其杀手锏之一。

**玄天斩灵剑**：仙界最强法宝之一，韩立在仙界后期获得，威力足以斩杀同阶仙人。

### 主要功法

**青元剑诀**：韩立从筑基期开始修炼的剑修功法，剑光分化，威力随境界提升而增强。

**大衍诀**：从上古阵法宗师大衍神君处获得的传承功法，专修神识。修炼后神识范围和精细度远超同阶，是韩立越级战斗的最大依仗之一。

**梵圣真魔功**：灵界获得的高阶功法，佛魔双修，兼具佛门正大和魔道霸道之长。

**时间法则**：韩立在仙界参悟的至高法则。掌握时间法则后，韩立可以操控时间流速，加速自身修炼或减速敌人，最终凭此成为道祖。

## 女主角：南宫婉

南宫婉是掩月宗长老，修仙界罕见的天灵根资质，修炼天赋远超常人。

她在筑基期时与韩立在血色禁地相遇。两人在禁地中被迫共处一间密室，发生了肌肤之亲。此后二人各自修炼，经历重重磨难后，在灵界重聚并正式结为道侣。

南宫婉性格清冷高傲、外冷内热。她对待修炼和感情同样认真，是韩立最重要的人生伴侣。在仙界篇中，南宫婉同样飞升仙界，与韩立并肩作战。

## 重要配角：大衍神君

大衍神君是上古时期的传奇人物，散修出身，自创大衍诀，将神识修炼到极其恐怖的境界。他是修仙界公认的阵法第一人，无人能及。

大衍神君寿元耗尽后，将一缕残魂封存在乱星海一座荒岛的洞府中。韩立偶然闯入，获得其传承。大衍神君的残魂与韩立达成交易：韩立继承大衍诀，同时帮助残魂完成复仇心愿。

虽然大衍神君出场时间有限（仅靠残魂存在），但他桀骜不驯、极度自负又极度聪明的形象给读者留下了极深的印象。他的大衍诀传承对韩立的成长起到了不可替代的作用——没有大衍诀强化神识，韩立根本无法越级对抗强敌。

## 修仙境界体系

凡人修仙传的修炼体系贯穿全书三界，严谨完整。

### 人界境界

炼气期：引气入体，共十三层，寿元约百岁。这是修仙的入门阶段，绝大多数凡人止步于此。

筑基期：筑就道基，寿元约二百五十岁。筑基后正式脱离凡人之躯，算是真正的修仙者了。筑基丹极其珍贵，是修士面临的第一道大坎。

结丹期：凝结金丹于丹田，寿元约六百岁。可御器飞行，在修仙界有了真正的地位。结丹被视为修士的分水岭——结丹成功则踏入高阶修士行列，失败则终生筑基。绝大多数修士都卡在这一关。

元婴期：金丹化婴，寿元约一千五百岁。元婴可离体出窍，瞬息千里。元婴修士在人界已是一方霸主，可开宗立派。

化神期：神识化形，寿元约三千岁。人界的最高境界，化神修士在整个界面不超过十人。达到化神后期可引动飞升之劫。

### 灵界境界

炼虚期：炼化虚空之力，适应灵界的灵气环境。

合体期：肉身与神识完全合一，实力产生质的飞跃。

大乘期：灵界最高境界，准备迎接飞升之劫。大乘修士在灵界已是无敌存在。

### 仙界境界

真仙 → 金仙 → 太乙玉仙 → 大罗金仙 → 道祖。道祖掌握至尊法则，为一方界面之主，仙界也只有极少数存在能达到此境。

### 渡劫

每个大境界的突破都需要渡天劫。天劫威力随境界递增：

- 筑基→结丹：三九雷劫
- 结丹→元婴：六九雷劫
- 元婴→化神：九九雷劫（最为凶险）
- 飞升：飞升之劫（九死一生）

渡劫需要准备大量丹药、法宝和阵法辅助。失败轻则修为倒退，重则形神俱灭。

## 掌天瓶

掌天瓶是凡人修仙传中最核心也最神秘的法宝。

### 来历
掌天瓶的真正来历极为神秘，韩立在七玄门后山的荒山洞穴中偶然获得。随着故事推进，才逐渐揭示它与仙界创世和时间法则的起源有关。

### 核心功能
每到月圆之夜，掌天瓶会自动吸收月光精华，在瓶中凝聚出几滴绿色液体——参天造化液。这种液体拥有逆天功效：

- 浇灌灵药可一夜催熟数百年甚至数千年药龄
- 直接服用可大幅增强修为
- 辅助炼丹可提高成丹率和丹药品质
- 长期使用可逐步改善修士的灵根资质

### 对韩立的意义
韩立能以四属性伪灵根这种废材资质修炼到道祖，掌天瓶是最根本的原因：

1. 提供无限的珍稀灵药——别人等数百年才成熟的药材，韩立一夜可得
2. 独家资源垄断——通过出售催熟的灵药获取海量灵石，购买顶级法宝和功法
3. 突破瓶颈——面对难以突破的境界，直接服用参天造化液强行冲关

没有掌天瓶，韩立连筑基都难以达成。
